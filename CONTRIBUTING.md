# Contributing

Contributions that improve the accuracy or usefulness of this tracker are
welcome. Good changes include:

- verifying achievement behavior against current GitHub documentation;
- improving the machine-readable status format;
- adding a reusable, tested audit command;
- documenting confirmed changes to achievement availability or thresholds.

## Workflow

1. Open an issue describing the gap or claim the relevant existing issue.
2. Create a focused branch and make one coherent improvement.
3. Link primary sources where GitHub documents the behavior.
4. Open a pull request explaining how the change was verified.

Do not submit artificial activity intended only to inflate achievement counts.
Stars, accepted answers, reviews, and co-authorship must reflect genuine
interest or collaboration.
